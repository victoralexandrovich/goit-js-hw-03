# GoIT JS Homework 03 - Arrays & Array Methods
JavaScript homework assignment for the GoIT course (Module 3). Topic: working with arrays, string manipulation, combining arrays, slicing, and filtering elements using loops and conditional statements.

**What was done:**
- Set up the repository `goit-js-hw-03` and configured the project structure according to the course requirements
- **Task 1 (Slug Generator):** Implemented the `slugify` function to convert article titles into readable URL slugs by splitting strings into words, lowering the case (`toLowerCase()`), and joining them with dashes (`-`)
- **Task 2 (Array Composition):** Implemented the `makeArray` function to combine two arrays (`firstArray` and `secondArray`) into a new one, returning either the full combination or a sliced version restricted by `maxLength` using `.slice()`
- **Task 3 (Number Array Filtering):** Implemented the `filterArray` function using a `for` loop and conditional `if` statement to filter numbers from an input array that are strictly greater than a given threshold value (`value`)
- Verified code formatting with Prettier and ensured zero errors or warnings in the browser console across all tasks via GitHub Pages

# Домашнє завдання 03 GoIT JS — Масиви та методи масивів
Практичне завдання з курсу JavaScript від GoIT (Модуль 3). Тема: робота з масивами, маніпуляції з рядками, об'єднання масивів, зрізи та фільтрація елементів за допомогою циклів і умовних операторів.

**Що зроблено:**
- Створено репозиторій `goit-js-hw-03` та налаштовано структуру проєкту відповідно до вимог курсу
- **Задача 1 (Генератор slug):** Реалізовано функцію `slugify` для створення читабельних URL-адрес із заголовків статей шляхом переведення в нижній регістр, розбиття на слова та об'єднання за допомогою тире (`-`)
- **Задача 2 (Композиція масивів):** Реалізовано функцію `makeArray` для об'єднання двох масивів в один із можливістю обмеження довжини результуючого масиву до заданого параметра `maxLength` за допомогою методу `.slice()`
- **Задача 3 (Фільтрація масиву чисел):** Реалізовано функцію `filterArray` із використанням циклу `for` та умовного оператора `if` для відбору й повернення лише тих чисел із масиву, які більші за порогове значення `value`
- Перевірено форматування коду за допомогою Prettier, а також відсутність будь-яких помилок чи попереджень у консолі на живій сторінці GitHub Pages
